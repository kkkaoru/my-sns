# TikTok

運用の指針は [公式情報ベースの運用ガイド](guide.md) を参照。

アカウントごとに `accounts/<account-id>/` を作成して運用します。

```bash
./scripts/new-account.sh tiktok <account-id>
```

## アカウント内の構成

| ディレクトリ | 用途 |
| --- | --- |
| `README.md` | プロフィール・コンセプト・運用ルール・KPI |
| `ideas/` | 企画ネタ |
| `scripts/` | ショート動画の台本・構成 |
| `drafts/` | キャプション・ハッシュタグの下書き |
| `published/` | 投稿済み動画の記録（URL・投稿日） |
| `assets/` | 素材（音源メモ・画像） |
| `analytics/` | 再生数・完全視聴率などの記録 |
