# TikTok 運用ガイド（公式情報ベース）

TikTok のアルゴリズムは非公開のため、TikTok 公式の説明だけを根拠にする（2026-11-08 調査）。
公式に書かれていないことは「推測」と明記する。

## 1. 公式が説明している推薦の仕組み

出典: [Introduction to the TikTok recommendation system](https://www.tiktok.com/transparency/en/recommendation-system) / [How TikTok recommends videos #ForYou](https://newsroom.tiktok.com/en-us/how-tiktok-recommends-videos-for-you)

- 予測している行動: いいね、シェア、コメント、「興味なし」、作者のフォロー、**最後まで見る**、**スキップ**、お気に入り、**一定時間以上見る**、サウンドをタップ
- 予測スコアを合計して動画ごとのスコアにする（重みは非公開）
- 動画の情報: 投稿時刻、投稿地域、作者の言語設定、サウンド、長さ、ハッシュタグ
- 個人化の要素: 地域、端末の言語、最近見た／最後まで見た／いいね／スキップした動画、フォロー関係
- 連続する動画が似すぎていると（例：同じサウンド）一部を入れ替える「類似チェック」がある
- 視聴者の地域のクリエイターがフィードに含まれるようにしている

→ 実践:
- 冒頭でスキップされない作り、最後まで見られる長さ
- キャプション・テロップは日本語、端末とアカウントの言語・地域を日本に
- ハッシュタグは内容に合うものを付ける（動画情報として使われる）
- 毎回同じサウンド・同じ構成にしない（類似チェックで入れ替えられやすい）

## 2. おすすめ（For You）に載らない条件：オリジナリティ

出典: [Integrity and Authenticity（コミュニティガイドライン）](https://www.tiktok.com/community-guidelines/en/integrity-authenticity) / [For You feed Eligibility Standards](https://www.tiktok.com/safety/en/policies-and-engagement/fyf-standards) / [Seller Center: Content Policy](https://seller-us.tiktok.com/university/essay?knowledge_id=6837891779151617)

- 「**新しい要素のない、オリジナルでない素材・再利用した素材**」はおすすめの対象外（コミュニティガイドライン）
- TikTok の Seller Center のポリシーでは:
  - 他のクリエイターや著作物のコンテンツは、**ナレーション、テキストの編集、本人の関わり**など大きな新しい視点を加えない限り投稿しない
  - **他サービスの透かし（ウォーターマーク）やロゴ**はオリジナルでないコンテンツのサインとされる
- 他人の知的財産権を侵害するコンテンツは削除される
- 公式ページによると、アナリティクスで「おすすめの対象外になった動画」を確認できる（X と違い、自分で状態を確認できる）

→ 実践:
- **他サービスから保存した動画（透かし付き）をそのまま上げない**。必ず元の編集データから書き出す
- 切り抜きに**自分のテロップ（ツッコミ・解説）、ナレーション、構成**を加える
  - 推測: 元の音声をそのまま字幕にしただけでは「新しい要素」と見なされない可能性がある（Creator Academy の例として第三者サイトが紹介。公式原文は未確認）
- 投稿後はアナリティクスで「おすすめ対象外」になっていないか確認する

## 3. 切り抜きアカウント向けチェック

- [ ] 活動者本人の許可・切り抜きガイドラインを確認した
- [ ] 透かし・他サービスのロゴがない元データから書き出した
- [ ] 自分のテロップ・ナレーション・構成など「新しい要素」を加えた
- [ ] 冒頭でスキップされない構成、最後まで見られる長さ
- [ ] 日本語のキャプション、内容に合うハッシュタグ
- [ ] 投稿後、アナリティクスでおすすめ対象外になっていないか確認した
