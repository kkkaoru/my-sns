# Instagram

アカウントごとに `accounts/<account-id>/` を作成して運用します。

```bash
./scripts/new-account.sh instagram <account-id>
```

## アカウント一覧

| account-id | アカウント名 | URL | ステータス |
| --- | --- | --- | --- |
| | | | |

## アカウント内の構成

| ディレクトリ | 用途 |
| --- | --- |
| `README.md` | プロフィール・コンセプト・運用ルール・KPI |
| `ideas/` | 企画ネタ |
| `reels/` | リールの台本・構成 |
| `stories/` | ストーリーズの構成 |
| `drafts/` | フィード投稿・キャプションの下書き |
| `published/` | 投稿済みの記録（URL・投稿日） |
| `assets/` | 画像・カルーセル素材 |
| `analytics/` | リーチ・保存数などの記録 |
