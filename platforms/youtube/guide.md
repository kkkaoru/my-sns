# YouTube 運用ガイド（公式情報ベース）

YouTube のアルゴリズムは非公開のため、YouTube 公式ヘルプに書かれている内容だけを根拠にする（2026-11-08 調査）。
公式に書かれていないことは「推測」と明記する。

## 1. 公式が説明している推薦の仕組み

出典: [How YouTube recommendations work](https://support.google.com/youtube/answer/16089387?hl=en)

- 推薦の材料: 視聴履歴、検索履歴、チャンネル登録、高評価、低評価、「興味なし」、「チャンネルをおすすめに表示しない」、満足度アンケート
- 満足度アンケートで「視聴時間だけでなく満足度」を把握している
- ホームのおすすめは主に視聴履歴をもとにする。Shorts フィードは「次に見たいと思われるもの」に合わせて個人化される
- クリエイター向け FAQ（古いページ）には「短い動画では**相対的な視聴時間**（どれだけの割合を見たか）、長い動画では絶対的な視聴時間がより重要」とある
  （[YouTube performance FAQ](https://support.google.com/youtube/answer/141805?hl=en)）

→ 実践:
- 冒頭で掴み、最後まで（できれば繰り返し）見られる長さにする
- 釣りタイトル・期待外れのサムネは避ける（低評価・「興味なし」・満足度アンケートの低評価は推薦を避ける材料になる）

## 2. Shorts の条件

出典: [Understand three-minute YouTube Shorts](https://support.google.com/youtube/answer/15424877?hl=en)

- **縦または正方形**で **3分以内** なら Shorts として扱われる（2024-10-15 以降のアップロード）。16:9 は通常の動画
- **1分を超える Shorts に著作権の申し立て（Content ID・手動どちらも）があると、世界中でブロック**される。再生もおすすめもされず、収益化もできない
  - 1分以下の Shorts はこの扱いの対象外
  - チャンネルへのペナルティはなく、申し立てが解決すれば再び見られるようになる
- 音楽の使用は多くの曲で最大90秒（曲によって60秒・30秒）

→ 実践:
- **曲が入る動画（歌・アカペラ×オケなど）は60秒以内**にする。1分を超えると、申し立て1件で完全に見られなくなる
- 配信 BGM が入った切り抜きも同じ。BGM の権利が不明なら60秒以内にするか、BGM を外す

### 60秒を超える場合の選択肢

| 選択肢 | 内容 | 向いているケース |
| --- | --- | --- |
| A. 横（16:9）の通常動画にする | 通常動画は Shorts の「1分超＋申し立て＝世界中でブロック」の対象外。ただし通常動画でも、申し立てがあれば権利者が「ブロック／広告収益化／視聴の追跡」を選べる（[Content ID 申し立て](https://support.google.com/youtube/answer/6013276?hl=en)） | 既存曲・BGM が入っていて、フル尺で出したい |
| B. Shorts のまま1〜3分にする | 申し立てが付かないと確信できる場合だけ。自作音源、YouTube オーディオライブラリの曲（Content ID の申し立てが付かないと公式に明記）など | 権利がクリアな音源だけ |
| C. 60秒以内に編集する／前後編に分ける | 一番安全。冒頭で掴む短い構成にもなる | 迷ったらこれ |

- アップロード画面の「**チェック**」で、公開前に著作権の問題を確認できる。予約公開にすれば公開日まで非公開のまま確認できる（[動画のアップロード](https://support.google.com/youtube/answer/57407?hl=en)）
  - ただしチェックは最終結果ではなく、公開後の手動の申し立てなどは防げない
- 推測: 3分を超える縦動画は Shorts の条件（3分以内）から外れるので通常動画扱いになると考えられる

## 3. 収益化するなら「再利用コンテンツ」に注意

出典: [YouTube channel monetization policies](https://support.google.com/youtube/answer/1311392?hl=en)

- **再利用コンテンツ**: YouTube や他サイトにすでにある素材を転用するチャンネルが対象
  - OK の例: 他のクリエイターの映像を編集し、**ストーリーや解説を加えたもの**、リアクションで元動画に解説を加えるもの
  - NG の例: 「好きな番組の場面を、物語性がほとんどない状態でつなげただけのクリップ」
  - **「元のクリエイターの許可があってもこのポリシーは適用される」**
- **不自然なコンテンツ**（2025-07-15 に「繰り返しの多いコンテンツ」から名称変更）: テンプレートで量産したように見える動画
- これらは収益化（YouTube パートナープログラム）の条件。動画が削除されるルールではない

→ 実践:
- 収益化を目指すなら、切り抜きに**自分の解説テロップ・ナレーション・構成（ストーリー）**を加える
- 毎回同じテンプレート構成で量産しない
- 収益化しないなら、このポリシーは直接は関係しない（著作権・許可は別問題として必要）

## 4. 切り抜きアカウント向けチェック

- [ ] 活動者本人の許可・切り抜きガイドラインを確認した
- [ ] 曲・BGM が入るなら60秒以内（超えるなら横の通常動画にするか、権利がクリアな音源だけにする）
- [ ] アップロード画面の「チェック」で著作権の問題がないことを確認した
- [ ] 縦（または正方形）・3分以内
- [ ] 冒頭で掴む構成、最後まで見られる長さ
- [ ] 収益化するなら、解説・ナレーション・構成で独自性を加えた
